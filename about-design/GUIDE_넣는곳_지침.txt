  바꿀 : 알림받기 + 리뷰로 최대 3,000원 혜택 + 돼지코 어댑터 증정

본문 첫 줄 (스토어 콘텐츠 > 텍스트)
  지금 : 스토어 알림받기만 해도 1,000원 할인 쿠폰을 드려요.
  바꿀 : 스토어 알림받기 1,000원 할인 쿠폰 + 리뷰 쓰면 최대 2,000원 적립, 최대 3,000원 혜택을 드려요.

본문 이어서 (있으면 유지, 없으면 추가)
  전기제품 구매 시 220V 돼지코 어댑터를 사은품으로 함께 보내드립니다.
  문의는 문자로 남겨주세요 · 010-5934-5488 (전화 상담 미운영)

[참고] 이미 설정된 이벤트 내용 (바꾸지 말 것, 확인용)
==================================================
- 사은품 문구 : 💜 전기제품 구매 시 220V 돼지코 어댑터 증정 💜  (에이바우트 하트 색은 보라 💜)
- 사은품 이미지 : 흰 배경, 글자 없는 어댑터 사진 (사은품 이미지에 글자를 넣으면 네이버 규정 위반)
- 복수구매 할인 : 2개 이상 구매 시 500원 할인
- 리뷰 포인트 : 텍스트 450원 / 포토·동영상 850원 (한 달 사용 리뷰도 동일) → 최대 2,000원
- 무이자 할부 : 3개월
- 알림받기 쿠폰 : 알림받기 1,000원 할인
- 알림받기 1,000원 + 리뷰 최대 2,000원 = 최대 3,000원 혜택
- 이달의 리뷰왕 : 매달 베스트 리뷰 선정, 네이버페이 포인트 10,000원 (선정 인원은 비공개)

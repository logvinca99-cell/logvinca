# 에이바우트 상세페이지 디자인 키트 (초안)

이름 뜻: about(~에 대하여) — 일상에 꼭 맞는 물건을 찾아 소개하는 스토어.
로고는 about의 첫 글자 ‘a.’, 메인 컬러는 딥 플럼.

## 컬러
| 이름 | HEX | RGB | 쓰는 곳 |
|---|---|---|---|
| 딥 플럼 | #553C8B | 85, 60, 139 | 테두리·아이콘·강조 글자 |
| 다크 플럼 | #2E2145 | 46, 33, 69 | 진한 띠·블록 |
| 라일락 | #D9C8FF | 217, 200, 255 | 진한 바탕 위 숫자·강조 |
| 라벤더 | #F1ECF8 | 241, 236, 248 | 보조면 |

## 결과물 (`output/`, 모두 PNG)
| 파일 | 용도 |
|---|---|
| `about_top.png` | 상단 (로고 + 옵션 확인 + 약 2주 안내), 1000 × 591 |
| `about_bottom_01~05.png` | 하단 5장, 위에서부터 순서대로 (1000px 폭, 장당 2000px 이하) |
| `about_watermark.png` / `about_watermark_white.png` | 워터마크 (투명, 약 500px) |
| `about_profile.png` | 프로필 1000 × 1000 |
| `about_banner.png` | 배너 1280 × 480 |
| `about_brand_guide.png` | 로고·컬러·글씨 크기·문구 규칙 |

## 문구 규칙
배송은 ‘주문 후 발주해 준비되는 상품’, ‘약 2주’로만 표현합니다.
통관·관부가세·구매대행 관련 문구는 넣지 않습니다.

## 다시 만들기
`node render.js` (글꼴은 `../onnuri-design/fonts/`의 Pretendard를 함께 씁니다)

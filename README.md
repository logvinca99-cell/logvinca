# 스마트스토어 찜 클릭기

네이버 스마트스토어 목록 페이지(80개씩 보기)에서 상품 카드의 찜(♡)을 한 페이지씩 누르는 프로그램입니다. 상품 상세 페이지에는 들어가지 않습니다.

## 설치

```bash
pip install -r requirements.txt
playwright install chrome   # PC에 크롬이 이미 있으면 생략 가능
```

## 실행

`zzim_start.bat`을 더블클릭하면 조작 창이 뜹니다. 크롬보다 항상 위에 떠 있습니다.

- 스토어 주소 칸에 주소를 넣고(여러 개면 한 줄에 하나) **▶ 시작**을 누릅니다.
- **⏸ 일시정지 / ▶ 계속**: 지금 누르는 상품까지 처리하고 멈춥니다.
- **■ 종료**: 작업을 끝냅니다. 다시 시작하면 남은 것부터 이어서 합니다.
- 진행률, 성공·이미 찜·실패·남은 개수, 지금 누르는 상품, 남은 시간이 표시됩니다.

검은 창 모드도 남아 있습니다.

```bash
python zzim.py --console https://smartstore.naver.com/abcstore
python zzim.py --console --file stores.txt
```

옵션
- `--sort-label "최신 등록순"`: 시작할 때 누를 정렬 버튼 글자. 진행하는 동안 순서가 바뀌지 않아야 누락이 없습니다.
- `--delay 600 6000`: 클릭 간격 자동 조절 범위(ms). 1.2초에서 시작해 거절이 없으면 15번마다 10%씩 빨라지고, 거절되면 바로 1.5배 이상 느려집니다. 최소값을 너무 줄이면 네이버가 거절하거나 계정이 제한될 수 있습니다.

## 동작 방식

1. 시크릿 창이 열리면 직접 로그인합니다. 로그인되면 자동으로 시작합니다.
2. "전체상품(총 N개)"를 읽어 페이지 수를 계산합니다.
3. 페이지마다 끝까지 스크롤한 뒤 카드를 한 번에 스캔합니다. 카드 안의 링크 `/products/<ID>`에서 ID를 읽고, 같은 카드 안의 찜 버튼과 짝을 짓습니다.
4. 카드를 화면 좌표순으로 정렬해 5개씩 행으로 묶고 차례로 클릭합니다. 이미 찜한 상품은 건너뜁니다. 클릭이 반영되지 않으면 4초, 8초, 12초 쉬고 다시 시도합니다.
5. 한 페이지가 끝나면 화면 아래 페이지 번호를 눌러 다음 페이지로 갑니다. 상품 목록이 실제로 바뀌었는지 확인합니다.
6. 결과는 `zzim_<스토어명>.csv`에 기록합니다. 중간에 멈춰도 다시 실행하면 처리한 ID는 건너뛰고 이어서 진행합니다.

## 상태 값 (CSV `status`)

| 값 | 의미 |
|---|---|
| clicked | 클릭 후 찜 상태로 바뀐 것을 확인함 |
| already | 실행 전에 이미 찜한 상태였음 |
| clicked? | 클릭은 했지만 상태를 판별하지 못함 |
| fail / error | 실패. 다시 실행하면 재시도함 |

## 처음 실행할 때 확인할 것

- 찜 버튼은 버튼 안에 "찜" 글자(숨김 텍스트 포함)가 있는지로 찾습니다. 찜 상태는 `aria-pressed` 속성이나 "찜하기 취소" 문구로 판별합니다. `clicked?`가 많이 나오면 F12로 버튼 구조를 확인해 `zzim.py`의 `STATE_JS`를 수정하세요.
- `--sort` 값(`st=` 파라미터)은 실제 목록 URL에서 확인하세요.
- 본인 계정 하나로 관심상품을 저장하는 용도로만 사용하세요. 여러 계정으로 찜 수를 부풀리면 네이버 약관 위반입니다.

# 스마트스토어 상품 등록기

엑셀(한 줄에 상품 하나)을 읽어 **네이버 커머스API**로 내 스마트스토어에 상품을 등록합니다. 브라우저를 조작하지 않고 네이버가 공식으로 제공하는 API를 씁니다.

## 처음 한 번 준비

1. [커머스API센터](https://apicenter.commerce.naver.com)에 스마트스토어 판매자 계정으로 로그인 → 애플리케이션 등록 → **애플리케이션 ID / 시크릿**을 받습니다.
2. 같은 곳에서 **API 호출 IP**에 이 PC의 공인 IP를 등록합니다. (안 하면 `GW.IP_NOT_ALLOWED` 오류)
3. `upload_config.example.json`을 복사해 `upload_config.json`으로 이름을 바꾸고 채웁니다. 조작 창의 **설정 열기**를 누르면 자동으로 만들어 줍니다.

| 항목 | 뜻 |
|---|---|
| client_id / client_secret | 1번에서 받은 값 |
| as_phone | A/S 전화번호 (상품정보제공고시에도 쓰임) |
| importer | 수입자 이름. 원산지가 해외일 때 필요 |
| origin_codes | 원산지 글자 → 네이버 원산지 코드. 중국(0200037) 외의 나라는 추가하세요 |
| delivery_company | 택배사 코드 (CJGLS=CJ대한통운, HANJIN, LOTTE, EPOST 등) |
| return_fee / exchange_fee | 반품 / 교환 배송비 |
| reupload_images | 썸네일을 내려받아 네이버 이미지 서버에 다시 올림 (API가 요구함, 켜 두세요) |
| delay_sec | 상품 하나 등록 후 쉬는 시간(초) |
| extra | 모든 상품에 덧붙일 API 필드. 예: `{"originProduct": {"deliveryInfo": {"deliveryAttributeType": "TODAY"}}}` |

## 실행

`upload_start.bat`을 더블클릭하면 조작 창이 뜹니다. (필요한 프로그램은 처음에 자동 설치)

1. **찾기**로 엑셀을 고르고 **검사**를 누릅니다. 등록하지 않고 변환만 해서 엑셀 옆 `upload_check` 폴더에 상품별 JSON을 저장합니다. API 키가 있으면 카테고리가 실제로 있는지도 확인합니다.
2. **1개만 시험 등록**을 켠 채 **▶ 등록**을 눌러 한 개를 올려 보고, 스마트스토어센터에서 상품이 제대로 보이는지 확인합니다.
3. 체크를 끄고 **▶ 등록**을 누르면 나머지를 모두 올립니다.

결과는 엑셀 옆 `upload_result_<엑셀이름>.csv`에 남습니다. 다시 실행하면 `success`인 줄은 건너뛰고 실패한 것만 다시 시도합니다.

검은 창 모드:

```bash
python smartstore_upload.py 상품.xlsx --console --check
python smartstore_upload.py 상품.xlsx --console --limit 1
python smartstore_upload.py 상품.xlsx --console
```

## 엑셀 열 → 등록 항목

| 엑셀 열 | 등록 항목 |
|---|---|
| 상품명 | 상품명 (100자까지) |
| 판매가 / 할인가 | 판매가. 할인가가 0보다 크고 판매가보다 작으면 그 가격이 되도록 즉시할인 |
| 재고수, 판매상태 | 재고, 판매중/판매중지 |
| 썸네일 | 첫 장 대표이미지, 나머지 추가이미지(최대 9장) |
| 상세설명 | 상세페이지 HTML 그대로 (네이버가 일부 태그는 걸러냄) |
| 카테고리 | `대>중>소>세` 이름으로 카테고리 번호를 찾음 |
| 옵션상품 | 조합형 옵션 그대로 |
| 상품태그 | 판매자 태그 (앞 10개) |
| 브랜드 / 제조사 / 모델명 | 네이버쇼핑 검색정보, 상품정보제공고시 |
| 원산지 | 원산지 코드 + 수입자 |
| 인증 | KC 인증 대상 제외 정보 |
| 판매자코드 | 판매자 관리코드 |
| 배송비 | 0이면 무료배송, 아니면 선결제 유료배송 |

## 실패했을 때

- `카테고리 ... 찾지 못했습니다`: 네이버 카테고리 이름이 바뀐 경우입니다. 엑셀의 카테고리 칸을 스마트스토어센터에 보이는 이름으로 고치세요. 카테고리 목록은 `category_cache.json`에 7일간 저장되니 지우면 새로 받습니다.
- `400 ... invalidInputs`: 뒤에 붙은 항목 이름(예: `originProduct.detailAttribute...`)이 잘못된 값입니다. 옵션 가격은 판매가 기준 허용 범위를 넘으면 거절됩니다.
- 상품정보제공고시는 모든 상품을 '기타 재화'로 등록합니다. 식품·전자제품 등 필수 고시가 다른 카테고리는 스마트스토어센터에서 고치거나 `extra`로 바꾸세요.
- 다른 판매자의 사진·상세페이지를 허락 없이 가져와 등록하면 저작권 침해로 상품이 삭제되거나 제재될 수 있습니다. 본인이 권리를 가진 상품 정보만 올리세요.

# 미스터 체리 상세페이지 상단·하단

에이바우트와 같은 구성·문구(해외·통관·구매대행 내용 없음)에 체리 색과 캐릭터를 입힌 버전입니다.

## 컬러
| 이름 | HEX | RGB |
|---|---|---|
| 체리 빨강 | #E23D55 | 226, 61, 85 |
| 진한 글자 | #2A1A1E | 42, 26, 30 |
| 버터 크림(빨강 위 강조) | #FFE9A8 | 255, 233, 168 |
| 연분홍(보조면) | #FFEEF0 | 255, 238, 240 |
| 잎사귀 초록 | #5DB26B | 93, 178, 107 |

캐릭터: 꼭지가 이어진 체리 두 알 (`src/mascot.js`, 자세: plain / wave / love)

`node render.js` (글꼴은 `../about-design/fonts/` 사용)

## 4차 시안: 쇼핑몰 공지 스타일 (`cherry4_*`, `src/top4.html`·`bottom4.html`·`style4.css`·`mascot4.js`) — 현재 추천안

## 5차 하단: 인덱스 탭 구획 (`cherry5_bottom_*`, `src/bottom5.html`) — 상단은 `cherry4_top.png` 그대로
섹션마다 01~06 번호가 달린 빨간 바인더 탭이 왼쪽·가운데·오른쪽으로 엇갈려 튀어나오고, 아래는 연분홍 판.
섹션별로 다른 그림: 배송=트럭 길 지도, 착불=크기 표시 박스 그림, 상품=CHECK POINT 번호, 교환=O/X, 취소=화살표 단계.
